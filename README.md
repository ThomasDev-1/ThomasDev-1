## Selected Work

### LarpTube

A full video-sharing platform built around accounts, discovery, subscriptions, libraries and content delivery.

Building LarpTube has given me the opportunity to work through many of the engineering challenges behind a large, content-driven web platform.

`Full-Stack Development` `Authentication` `Video` `Web Architecture`

[Visit LarpTube](https://larptube.com/)

### ScheduleX

A mobile timetable application I built after becoming frustrated with the software I used at university.

ScheduleX connects to WebUntis and provides lesson information, schedule changes, notifications, subject customisation and calendar views. It has since moved into real-world testing with students.

`Android` `APIs` `Notifications` `Product Design`

### Outhatched

An online multiplayer game built in Unity, combining aerial movement, character abilities, combat and objective-based gameplay.

The project has involved multiplayer systems, backend services, REST APIs and real-time game architecture.

`C#` `Unity` `Multiplayer` `REST APIs`

[Visit Outhatched](https://outhatched.com/)
